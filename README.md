# netflix-clone-html-css
## About
This project is a clone of the Netflix landing page built using HTML and CSS. It focuses on layout design using Flexbox.

## Features
* Hero section with background image
* Navigation bar
* Responsive layout using Flexbox
* Clean UI structure

## Technologies Used
* HTML
* CSS (Flexbox)

## Purpose
To practice layout design and improve CSS skills using Flexbox.

## Future Improvements
* Add responsiveness for mobile devices
* Improve styling and animations
* Add more sections similar to Netflix
